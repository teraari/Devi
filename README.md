**Автономный интеллектуальный редактор русскоязычных текстов с локальным искусственным интеллектом.**

Devi — настольное приложение для проверки, исправления и улучшения текстов на русском языке. Программа объединяет собственный языковой движок, морфологический анализатор и локальную большую языковую модель.

Главная особенность Devi — работа непосредственно на компьютере пользователя. Для проверки и редактирования текста не требуется подключение к интернету или отправка документов в облачные ИИ-сервисы.

##  Возможности

### Проверка русского языка
Devi использует собственный языковой движок, построенный на основе Hunspell и дополнительных алгоритмов анализа текста.
- Проверка орфографии с учётом словоформ, окончаний и приставок.
- Анализ морфологии: части речи, род, число и падеж.
- Проверка грамматических ошибок и согласования слов.
- Поиск пунктуационных ошибок.
- Проверка употребления вводных слов и знаков препинания.
- Обнаружение контекстных ошибок (паронимы, плеоназмы).
- Распознавание URL, адресов электронной почты и сложных слов.

### Исправление с помощью ИИ
В Devi интегрирована локальная языковая модель **Saiga 8B**.
- Делает формулировки более естественными.
- Повышает связность и логичность текста.
- Исправляет неудачные выражения.
- Сохраняет исходный смысл при редактировании.
- Подсвечивает **только измененные ИИ слова** зеленым цветом, не закрашивая весь абзац.

Модель запускается локально и не требует обращения к облачным API.

### Удобный редактор
- Отображение статуса проверки и сообщения «Ошибок не найдено!».
- Отдельная панель найденных ошибок с фильтрацией.
- Счётчик слов и лимит на обработку ИИ (для защиты ОЗУ).
- Переименование документов двойным щелчком.

### Работа с документами
| Формат | Чтение | Сохранение / Экспорт |
|---|---|---|
| TXT | ✅ | ✅ |
| DOCX | ✅ (с сохранением форматирования) | ✅ |
| HTML | ❌ | ✅ |
| PDF | ❌ | ✅ (формат A4) |

##  Локальный искусственный интеллект

Devi использует модель Saiga 8B, работающую непосредственно на компьютере пользователя.

- Однократная загрузка модели в память (Singleton) при первом запуске.
- Поддержка аппаратного ускорения на видеокартах **NVIDIA** (через CUDA).
- Выгрузка части слоёв модели на GPU для ускорения генерации.

**Важно:** производительность ИИ зависит от процессора, видеокарты, оперативной памяти и параметров запуска модели.

---

##  Конфиденциальность

Devi — полностью автономный инструмент.
- Проверка текста и работа ИИ выполняются локально.
- Для основных функций не нужны облачные сервисы.
- Работа приложения не зависит от наличия интернет-соединения (после скачивания модели и словарей).

##  Технологии

- **C# / .NET 10**
- **Avalonia UI** — кроссплатформенный интерфейс.
- **AvaloniaEdit** — текстовый редактор с подсветкой.
- **CommunityToolkit.Mvvm** — архитектура MVVM.
- **Hunspell** — основа проверки орфографии.
- **LLamaSharp** (llama.cpp) — движок для работы с нейросетью.
- **Saiga 8B** — локальная языковая модель.
- **QuestPDF** — формирование PDF-документов.

### Архитектура
| Проект | Назначение |
|---|---|
| `Proofreader.Core` | Основные модели и интерфейсы |

| `Proofreader.Language` | Языковой движок, анализ текста и ИИ |
| `Proofreader.App` | Пользовательский интерфейс |

##  Системные требования

- **ОС:** Windows 10 или Windows 11.
- **ОЗУ:** Минимум 8 ГБ (рекомендуется 16 ГБ для комфортной работы 8B модели).
- **Место на диске:** ~6 ГБ (программа + модель).
- **GPU (опционально):** Видеокарта NVIDIA (GTX 1050 Ti и выше) для ускорения ИИ.

##  Установка и запуск

Готовая сборка публикуется в разделе [GitHub Releases](../../releases).

**Шаг 1. Скачайте программу**
1. Перейдите в раздел Releases.
2. Скачайте архив с программой `Devi-v1.0.0.zip` и распакуйте его в любую папку.

**Шаг 2. Скачайте модель ИИ (Обязательно)**
Из-за ограничений GitHub на размер файлов (макс. 100 МБ), модель скачивается отдельно.
1. Скачайте файл `saiga_yandexgpt_8b.Q4_K_M.gguf` (~4.6 ГБ) по ссылке: *(вставьте сюда ссылку на HuggingFace или Яндекс.Диск)*.
2. Переименуйте скачанный файл в **`saiga.gguf`**.
3. Переместите файл `saiga.gguf` в папку **`Dictionaries`**, которая находится рядом с `Devi.exe`.

**Шаг 3. Запуск**
Запустите **`Devi.exe`**. При первом нажатии кнопки «Исправить с ИИ» модели потребуется 10–20 секунд на загрузку в память.
